<1번째 과제 완료>
txt, btn 같은 헝가리안 표기법으로 도구 이름을 바꾸는 과정에서 헝가리안 표기법에 익숙해질 필요성을 좀 느꼈습니다.
배경색은 어떻게 할지 고민하고 있어서 조금 더 기능을 구현해보고 2번째에 적절한 색깔로 입힐 생각입니다. 
대신에 저번에 배웠던 사진을 공백에 넣어 꾸며봤습니다. 
그리고 다음에는 (여기에 입력하세요) 매사자를 흐릿하게하고 클릭하면 입력할 때 메시지가 보이지않게끔하는 기능과 엔터로 입력과 전송을 자유롭게 하는 기능,
clear 후에도 (여기에 입력하세요)가 보이게끔 하는 기능을 추가 해보곘습니다.

<2번째 과제 완료>
컴퓨터에서 README.txt 파일을 만들어서 1번째 커밋 후에 REAME.txt 파일에 추가 작성을 하려고 파일을 열어보니 1번째 커밋때 작성했던 글이 없어서 그냥 2번째 과제 리드미를 작성하고 커밋하니 동기화를 하라해서 동기화 후에 커밋하고 리드미 파일을 확인 차 열어보니 작성한 2번째 리드미가 사라졌고, 과제 진행에 있어 시간이 부족해 깃허브 리드미에 작성함에 양해를 구합니다. (다음 시간에는 해결해보겠습니다)

목표: 입력창의 기존 메시지 clear, 전송 후 입력창에 포커스 자동화, 엔터키로 전송 기능 추가, 공백만 전송 방어
앞 2가지는 수월하게 진행했지만 엔터키로 전송 이벤트를 txtMS에 추가할지, 버튼에 추가할지 모르겠어서 확인한 결과 txtMS에 추가해야함을 알게되었습니다.
그리고 공백만 전송은 (string.IsNullOrWhiteSpace(txtMS.Text)를 if문으로 확인하여 공백이 없으면 전송, 있으면 return되게끔 했습니다.


<3번째 과제 완료>
목표: 타임스탬프와 메시지 카운팅 추가, Trim()으로 문자열 정제
타임스탬프와 Trim()의 경우 오늘 배웠던 내용이기에 앞 3_1 내용을 보면서 했고, 카운팅은 변수 하나 더 만들어야하는걸 생각하지 못해 AI의 도움을 살짝 받아서 진행했습니다. $"[{DateTime.Now:HH:mm:ss}] {typed_msg}"는 어렵지 않았는데 변수를 생각하지 못했던거 같아 배웠습니다.

<4번째 과제 완료>
목표: 선택 삭제/전체 삭제 버튼 만들기, 글자 수 50으로 제한

lsMS 채팅을 Clear로 삭제해줬습니다. 그리고 선택 삭제의 경우 어떻게 해야할지 몰라 제미나이의 도움을 받아 if문으로 lbMS에서 채팅을 선택하면 삭제, 선택 안하면 선택하라는 메시지가 뜨게끔 했습니다. 여기서 채팅 수 카운팅이 적용되지않아서 카운팅도 추가했습니다. 
강의 3_2 ppt를 참고하여 if문에 txtMS.Text에 .Length를 추가해서 메시지 길이를 50보다 크면 메시지 박스를 띄우고 return하게끔 했습니다.

이후엔 배경색을 백지헌 사진과 자연스럽게 하려다보니 어두운 색으로 점차 하게되었고, 제미나이의 도움을 받아서 txtMS의 (여기에 입력하세요)를 포커스가 가면 없어지고 포커스를 다른 곳으로 하면 다시 나오게끔하였고, 또한 메시지를 입력하고 lsMS에 보낼 때 안나오게끔 하였습니다.
